# コールセンターシステム - 画面モックアップ

## 概要

フェーズ1（基本機能開発）の画面モックアップ集です。
全9画面をHTML/CSS（Bootstrap 5）で作成しています。

## 画面一覧

### オペレーター用画面（5画面）

1. **01_login.html** - ログイン画面
   - ユーザー認証
   - ログイン状態保持オプション

2. **02_dashboard.html** - ダッシュボード画面
   - 本日の対応状況（統計カード）
   - 自分の対応中案件リスト
   - お知らせ表示

3. **03_customer_search.html** - 顧客検索・登録画面
   - 顧客検索（電話番号、顧客コード、氏名、氏名カナ）
   - 検索結果一覧表示
   - 新規顧客登録モーダル

4. **04_inquiry_create.html** - 問い合わせ登録画面
   - 顧客情報表示
   - 問い合わせ基本情報入力
   - カテゴリ・製品・優先度選択
   - 担当者割当（自動/手動/自分）

5. **05_inquiry_detail.html** - 問い合わせ詳細画面
   - タブ1: 詳細情報表示
   - タブ2: 対応履歴表示・追加
   - 顧客情報サイドパネル
   - SLAタイマー表示

### 管理者用画面（4画面）

6. **06_category_master.html** - カテゴリマスタ管理画面
   - カテゴリ一覧表示（3階層：大・中・小分類）
   - 新規カテゴリ追加モーダル
   - SLA時間設定

7. **07_product_master.html** - 製品マスタ管理画面
   - 製品一覧表示
   - 新規製品追加モーダル
   - 製品タイプ（Hardware/Software/Service）管理

8. **08_user_master.html** - ユーザーマスタ管理画面
   - ユーザー一覧表示
   - 新規ユーザー追加モーダル
   - 役割・スキルレベル・ステータス管理

9. **09_department_master.html** - 部署マスタ管理画面
   - 部署一覧表示（階層構造対応）
   - 新規部署追加モーダル
   - 親部署・責任者設定

## 使用技術

- **HTML5**
- **CSS3**
- **Bootstrap 5.3.0**
- **Bootstrap Icons 1.11.0**

## カラースキーム

- **プライマリカラー**: グラデーション紫（#667eea → #764ba2）
- **成功**: グリーン（#28a745）
- **警告**: イエロー（#ffc107）
- **危険**: レッド（#dc3545）
- **情報**: ブルー（#17a2b8）

## 閲覧方法

各HTMLファイルをブラウザで直接開いてください。
インターネット接続が必要です（Bootstrap・アイコンはCDNから読み込み）。

```bash
# 例: Windowsの場合
start mockups/01_login.html

# 例: Macの場合
open mockups/01_login.html

# 例: Linuxの場合
xdg-open mockups/01_login.html
```

## 注意事項

- これらはデザインモックアップです。実際の機能は実装されていません。
- ボタンクリックやフォーム送信は動作しません（静的HTML）。
- 実装時は、バックエンドAPIと連携する必要があります。

現在はデスクトップ専用ですが、実装時は以下のブレークポイントを考慮してください：
- デスクトップ: 1920x1080
- ノートPC: 1366x768
- タブレット: 1024x768（将来対応）

- キーボード操作対応

- カラーコントラスト比の確保

- 画像の遅延読み込み
